Getting Started

What is Fast HTML MCP?▾
Fast HTML MCP is a Model Context Protocol server that generates HTML from AI agents. It provides 15 tools, 22 components, and 25 templates for lightning-fast HTML generation with sub-second patch times.
How do I install Fast HTML MCP?▾
Run npx -y @aimino/fast-html-mcp-server in your terminal. No dependencies or configuration files needed. Works on Node.js 20+.
Which AI platforms are supported?▾
Fast HTML MCP works with Cursor, VS Code (via GitHub Copilot MCP), Claude Desktop, Claude Code, and Windsurf. See our integration guides for platform-specific setup.

Templates & Components

How many templates are available?▾
There are 25 templates across 6 categories: General Purpose (11), Business (5), Communication (5), Technical (3), Research (7), and Presentation (1). Each template has customizable variables and supports embedded components.
Can I create custom templates?▾
Yes! Use the register_template tool to register your own doT.js templates at runtime. You can also add templates to the community-templates/ directory for persistent availability.

API & Tools

What's the difference between render_page and write_raw_html?▾
render_page composes pages from structured component specs using doT.js templates, while write_raw_html writes a raw HTML string (optionally template-wrapped) directly to a file.
How does patch_html work?▾
It replaces the inner content of matched elements via CSS selectors using the parse5 AST. For #id selectors, it uses a direct text substitution fast-path (~10x faster than full AST parsing).

Deployment

Can I run Fast HTML MCP as a REST API?▾
Yes! Set TRANSPORT=api or TRANSPORT=http to start the server in REST API mode. When using http mode, both MCP and REST are available on the same port.
Is there a Docker image available?▾
Yes, we publish Docker images. Use the provided Dockerfile and docker-compose.yml for containerized deployments.
