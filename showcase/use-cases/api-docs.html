REST API v3

Fast HTML MCP API Reference

Build, read, and patch HTML documents programmatically

Core Endpoints

POST/v1/renderCompose a page from components
Accepts a template name and an array of section specifications. Returns the fully rendered HTML document.
⏱ ~900ms📦 Content-Type: application/json
{
  "template": "report",
  "sections": [
    { "component": "hero", "props": { "title": "Q3 Report" } },
    { "component": "data-table", "props": { "headers": ["Metric","Value"], "rows": [["Revenue","$1.2M"]] } }
  ],
  "output_path": "/tmp/report.html",
  "options": { "title": "Q3 Report" }
}
templatestring (required)One of 25 available templatessectionsarray (required)Component specs with component name and propsoutput_pathstring (optional)File path for output HTML. If omitted, returns inline
POST/v1/render/htmlRaw HTML wrapped in a template
Pass raw HTML content and optionally wrap it in a template shell.
{
  "template": "minimal",
  "content": "<h1>Hello World</h1>"
}
PATCH/v1/patchUpdate existing HTML by CSS selector
Replace the inner content of elements matched by a CSS selector. Uses parse5 AST for complex selectors and a #id fast-path for simple id lookups.
{
  "file_path": "/tmp/page.html",
  "selector": "#title",
  "html": "<h1>New Title</h1>"
}

Utility Endpoints

GET/v1/templatesList available templates
Returns all 25 templates organized by category with metadata.
GET/v1/componentsList available components
Returns all 22 components organized by category with prop schemas.
