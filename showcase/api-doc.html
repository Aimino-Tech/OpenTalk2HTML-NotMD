Integrations
The Payments API allows you to create, capture, refund, and manage payments. Supports credit cards, digital wallets, and bank transfers. All amounts are in cents (smallest currency unit).
Create and manage recurring billing with support for monthly, yearly, and custom billing periods. Automatic retry logic with configurable schedules and dunning management.
Receive real-time notifications for payment events including succeeded, failed, refunded, and disputed. Webhooks are delivered with at-least-once semantics and signature verification.

// Create a payment intent
const stripe = require('stripe')('sk_test_...');

const paymentIntent = await stripe.paymentIntents.create({
  amount: 2000, // $20.00
  currency: 'usd',
  customer: 'cus_abc123',
  metadata: { order_id: 'ord_789' },
  automatic_payment_methods: { enabled: true },
});

console.log(paymentIntent.id); // pi_xyz789
