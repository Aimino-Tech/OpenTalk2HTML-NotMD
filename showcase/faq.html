Fast HTML MCP — Frequently Asked Questions

Everything you need to know about the Fast HTML MCP server and its five-tier architecture

What is Fast HTML MCP? ▼
Fast HTML MCP is a Model Context Protocol server that provides lightning-fast HTML generation from AI agents. It features a five-tier architecture: Assembly, Patch, Read, Raw, and Consistency tiers, with 15 tools, 22 components, and 25 templates.
How is it different from Playwright or Puppeteer? ▼
Fast HTML MCP operates directly on strings and AST with no headless browser overhead. Cold start to first render is ~1.5s compared to 5-15s for Playwright/Puppeteer. It also offers token-efficient compression modes that reduce HTML size by 40-97%.
What templates are available? ▼
25 templates across 6 categories: General Purpose (11), Business (5), Communication (4), Technical (3), Research (8), and Presentation (1). Templates range from reports and dashboards to scientific papers and pitch decks.
How do I get started? ▼
Install with npx: npx -y @aimino/fast-html-mcp-server. Then add the MCP server to your client config. Use list_templates and list_components to discover available options, then render_page to build your first page.
Does it support custom templates? ▼
Yes! Use the register_template tool to add custom templates at runtime. Templates use doT.js syntax with the {{=it.content}} placeholder for rendered sections. Custom templates are immediately available for use.
