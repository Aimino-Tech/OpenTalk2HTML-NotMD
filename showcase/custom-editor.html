API Playground

Try out API endpoints directly in the browser with live response preview

The REST API playground allows you to test endpoints, view responses, and generate client code. Try the GET /users endpoint to see a paginated response with user data. Use the authentication header field to test different auth scopes.
The GraphQL playground provides an interactive query editor with schema documentation, query validation, and real-time response preview. Write queries, mutations, or subscriptions and see results instantly.
Test real-time WebSocket connections with the interactive WebSocket playground. Send messages, view connection logs, and monitor latency in real-time.
bash
# Test the user endpoint
curl -X GET https://api.example.com/v2/users \
  -H "Authorization: Bearer sk_test_..." \
  -H "Content-Type: application/json" \
  | jq '.data[:3] | {users: [.[] | {name, email, role}]}'
🔌
Authentication All playground requests include your current session token automatically. Use the 'Impersonate' button to test different permission levels.
